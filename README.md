# 🤖 مشروع الروبوت الصديق - تطوير فارس
هذا المشروع هو عبارة عن مساعد ذكي بالذكاء الاصطناعي يقدر يقسر معاك ويضحك.

## 🚀 المميزات:
* ردود فعل ذكية (يضحك، يقسر، يمد معلومات).
* واجهة مستخدم (UI) عصرية ومظلمة.
* يدعم النطق الصوتي (Text-to-Speech).

## 🛠️ التقنيات المستخدمة:
* Python & Flask.
* JavaScript & HTML/CSS.
